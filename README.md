# 🚀 Job Application Tracker Portal (MERN Stack)

## 📌 Overview
Full stack MERN project to track job applications, statuses, and interviews with authentication and dashboard.

---
## ⚡ Features
- JWT Login/Register
- Add/Edit/Delete Jobs
- Status Tracking (Applied, Interview, Offer, Rejected)
- Protected Routes
- Dashboard UI
---

## 🛠 Tech Stack
React.js, Node.js, Express.js, MongoDB, Mongoose, JWT, Axios

---
## 📁 Structure
```
client/ (React UI)
server/ (Express API)
images
```

---
## 🔗 APIs
- GET /api/jobs  
- POST /api/jobs/add  
- PUT /api/jobs/:id  
- DELETE /api/jobs/:id  
- POST /api/auth/register  
- POST /api/auth/login  
---
## 🚀 Run Project
Backend:
```
cd server && node server.js
```
Frontend:
```
cd client && npm start
```
## 🌐 Env
```
MONGO_URI=your_url  
JWT_SECRET=your_secret  
PORT=5001
```
